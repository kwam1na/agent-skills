# Custom Agent Skills

This repository syncs only the custom local Codex skills from `/Users/kwamina/.codex/skills`.

## Included Skills

- `bootstrap-agent-harness`
- `compound-delivery-kernel`
- `create-linear-ticket`
- `deliver-work`
- `designing-frontends`
- `execute-linear-ticket`
- `frontend-skill`
- `playwright`
- `ticket-retrospective`

## Excluded

- packaged/system skills such as `.system`
- support folders such as `references` and `tests`
- bundled or non-custom skill trees such as `compound-engineering`

## Usage

Clone this repo anywhere and wire the folders in `skills/` into your client's normal skill discovery path.
