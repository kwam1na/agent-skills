# Agent Skills Mirror

This repository mirrors the current local Codex skills directory from `/Users/kwamina/.codex/skills`.

## Layout

- `skills/`: direct mirror of the local skills tree, including user-authored skills and supporting folders such as `.system`, `references`, and `tests`

## Usage

Clone this repo anywhere and wire `skills/` into your client's normal skill discovery path.
When the local skills directory changes, resync it into this repository and push the update.
